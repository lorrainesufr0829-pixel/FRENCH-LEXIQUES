# 首页每日推送内容维护说明

首页每日推送采用**人工精选 + 公共共享**模式，不从用户个人词库抽取内容，也不自动抓取第三方网站。

## 每日精选单词

维护文件：`js/daily-content.js` 中的 `words` 数组。

- 所有访客共享同一组词汇。
- 系统按 UTC 日期轮换，所有用户同一天看到相同单词。
- 每条词汇应提供法语词形、IPA、词性、法语释义、中文释义、英文释义、例句及译文。
- 当前内置 7 条示例词条；替换或扩充数组即可更新公共词库。

## 每日阅读

维护同一文件中的 `article` 常量。发布时填写：

- `title`：对象包含 `en`、`fr`、`zh` 三种标题
- `summary`：对象包含三种语言的简短摘要
- `url`：France 24 法语原文链接
- `publishedAt`：文章发布日期
- `level`：建议难度，如 B2–C1

建议优先选择社会、政治、教育、国际事务主题，并确认链接可正常打开。

## 每日听力

维护同一文件中的 `listening` 常量。发布时填写：

- `title`：对象包含 `en`、`fr`、`zh` 三种标题
- `summary`：对象包含三种语言的简短介绍
- `audioUrl`：可直接播放的音频文件 URL
- `transcriptUrl`：文字稿页面链接；没有文字稿时可省略
- `publishedAt`：节目发布日期
- `duration`：节目时长
- `level`：建议难度

优先选择 RFI 的法语学习内容或附文字稿的节目。不要把普通网页地址填入 `audioUrl`；该字段必须是可播放的音频文件地址。

## 发布流程

1. 核对原文/音频链接、发布日期、主题和难度。
2. 更新 `js/daily-content.js` 中对应内容。
3. 提交到 GitHub 默认分支。
4. 打开首页检查三种语言、深色模式、手机布局和外部链接。

阅读或听力尚未发布时，首页会显示准备提示，不会伪造文章、音频或发布日期。
